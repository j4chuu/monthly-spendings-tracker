# Monthly Spend Tracker

Monthly Spend Tracker is a monthly budget app. You set a total, split it into categories, log expenses, and see remaining money plus a spending chart. There is no login — a `sessionId` in `localStorage` scopes the data.

## Made with

Next.js (App Router), React, TypeScript, Tailwind CSS, shadcn/ui, Radix UI, tRPC, TanStack Query, Prisma, PostgreSQL (Supabase), Zustand, Zod, Recharts, Vitest, and Vercel.

## Run locally

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Environment variables

`DATABASE_URL`
